
# Environment Setup Script

This script will:
1.  Download JDK 17 (Eclipse Adoptium)
2.  Download Apache Maven 3.9.6
3.  Extract them to `C:\Users\vadde\tools`
4.  Update your User PATH environment variable permanently.

Reference:
- JDK Url: https://api.adoptium.net/v3/binary/latest/17/ga/windows/x64/jdk/hotspot/normal/eclipse?project=jdk
- Maven Url: https://archive.apache.org/dist/maven/maven-3/3.9.6/binaries/apache-maven-3.9.6-bin.zip
