# Smart College Cafeteria 
## Food Ordering System

**Presented by:** [Your Name]
**Technology:** Java Spring Boot + React

---

# 1. The Problem
**Why do we need this system?**

*   **Long Queues:** Students waste break time waiting in line.
*   **Manual Errors:** Cash handling and manual token systems are prone to mistakes.
*   **Inefficiency:** Kitchen staff cannot predict demand or track orders efficiently.
*   **No Feedback:** Difficult to collect ratings on food quality.

---

# 2. The Solution
**A Full-Stack Digital Platform**

*   **Digital Ordering:** Order from anywhere on campus.
*   **Real-time Tracking:** See when your food is "Preparing" or "Ready".
*   **Admin Dashboard:** easy menu management and sales oversight.
*   **Kitchen Display:** Chefs see live orders instantly.

---

# 3. Technologies Used
**Building a Robust Architecture**

*   **Backend:** Java 21, Spring Boot 3 (Validations, Security, JPA).
*   **Frontend:** React.js (Hooks, Context API), Vite, Bootstrap.
*   **Database:** MySQL 8.0 (Reliable Relational Data).
*   **Security:** JWT (JSON Web Tokens) for Stateless Authentication.
*   **Deployment:** Railway (Backend/DB) + Vercel (Frontend).

---

# 4. Key Features

## User/Student
*   Sign Up / Login / Forgot Password.
*   Browse Menu with Categories.
*   Add to Cart & Checkouts.
*   Order History & Live Status.

## Admin/Hostel
*   Manage Menu (Add/Edit/Delete Items).
*   View All Orders.
*   User Management.

---

# 5. System Flow (Demonstration)

1.  **Login:** User logs in securely.
2.  **Order:** User selects "Chicken Biryani" -> Adds to Cart -> Places Order.
3.  **Kitchen:** Chef sees order on Dashboard -> Marks "Preparing".
4.  **Notification:** User sees status update.
5.  **Pickup:** Chef marks "Ready" -> User collects food -> Email Sent.
